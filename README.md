# VisionChip AI – Intelligent Restoration for Semiconductor Inspection

## 📌 Project Overview
VisionChip AI is an AI-powered image restoration system developed to enhance degraded semiconductor wafer inspection images. The project uses deep learning and image processing techniques to remove noise, reduce blur, improve contrast, and preserve critical defect information for accurate semiconductor quality inspection.

---

## 🎯 Problem Statement
**AI-Based Restoration of Degraded Images for Semiconductor Inspection (KLA)**

Semiconductor inspection images often suffer from noise, blur, low contrast, and imaging artifacts. These degradations make it difficult to identify microscopic defects accurately. VisionChip AI aims to restore degraded images while preserving defect details using advanced AI models.

---

## 💡 Proposed Solution
The proposed system applies image preprocessing and deep learning-based restoration techniques to improve the quality of degraded semiconductor images. The restored images help engineers perform more accurate defect detection and quality analysis.
